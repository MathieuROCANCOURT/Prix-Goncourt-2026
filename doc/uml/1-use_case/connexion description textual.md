# Description textuelle pour la connexion d'un jury

| Elément                  | Description                                                                                                                                            |
|--------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------|
| Nom du cas d’utilisation | Connexion                                                                                                                                              |
| But / Objectif           | Le jury ou le directeur du jury se connecte à son compte                                                                                               |
| Acteur principal         | Jury ou directeur du jury                                                                                                                              |
| Scénario principal       | <ol><li>L'utilisateur visite le site</li><li>Remplit son nom d'utilisateur et son mot de passe</li><li>Clique sur "Se connecter".</li></ol>            |
| Scénarios alternatifs    | <ul><li>Nom d'utilisateur et/ou mot de passe incorrect : affichage d'un message d'erreur.</li><li>L'utilisateur peut réessayer la connexion.</li></ul> |
| Postconditions           | Le jury ou le directeur du jury a un compte.                                                                                                           |
