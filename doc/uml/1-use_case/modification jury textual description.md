# Description textuelle pour la modification d'un jury

| Elément                  | Description                                                                                                                                                                                                                                                                                                          |
|--------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Nom du cas d’utilisation | Modification d'un jury                                                                                                                                                                                                                                                                                               |
| But / Objectif           | Modifier les coordonnées d'un jury pour le prix Goncourt.                                                                                                                                                                                                                                                            |
| Acteur principal         | Administrateur                                                                                                                                                                                                                                                                                                       |
| Précondition             | Au moins 1 jury a déjà été ajouté.                                                                                                                                                                                                                                                                                   |
| Scénario principal       | <ol><li>L'administrateur clique sur le jury</li><li>L'administrateur change les données du jury sélectionner.</li><li>L'administrateur confirme la modification des coordonnées saisies.</li><li>Le système récupère les informations</li><li>Une confirmation de la modification des données est affichée</li></ol> |
| Scénarios alternatifs    | <ul><li>En cas d'erreur de saisie d'une des données, demande de correction.</li></ul>.                                                                                                                                                                                                                               |
