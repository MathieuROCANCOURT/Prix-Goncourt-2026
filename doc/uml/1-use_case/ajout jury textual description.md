# Description textuelle pour l'ajout d'un jury

| Elément                  | Description                                                                                                                                                                                                                                                                                        |
|--------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Nom du cas d’utilisation | Ajout d'un jury                                                                                                                                                                                                                                                                                    |
| But / Objectif           | Ajouter un jury pour le prix Goncourt.                                                                                                                                                                                                                                                             |
| Acteur principal         | Administrateur                                                                                                                                                                                                                                                                                     |
| Scénario principal       | <ol><li>L'administrateur clique sur "Ajouter un jury"</li><li>L'administrateur met les données du jury.</li><li>L'administrateur confirme l'ajout des coordonnées saisies.</li><li>Le système récupère les informations</li><li>Une confirmation de l'ajout des données est affichée</li></ol>     |
| Scénarios alternatifs    | <ul><li>En cas d'erreur de saisie d'une des données, demande de correction.</li><li>Si il y a 9 jurys et qu'aucun est président, envoyer un message que le dernier jury ajouté est le président du jury.</li><li>S'il y a déjà 10 jurys, l'administrateur ne peut plus ajouter de jury.</li></ul>. |
