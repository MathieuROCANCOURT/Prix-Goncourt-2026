# Description textuelle pour la modification d'un livre

| Elément                  | Description                                                                                                                                                                                                                                                                                                                                                                  |
|--------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Nom du cas d’utilisation | Modification d'un livre                                                                                                                                                                                                                                                                                                                                                      |
| But / Objectif           | Modifier les données d'un des livres au prix Goncourt.                                                                                                                                                                                                                                                                                                                       |
| Acteur principal         | Administrateur                                                                                                                                                                                                                                                                                                                                                               |
| Scénario principal       | <ol><li>Le système affiche la liste des livres.</li><li>L'administrateur clique sur le livre qu'il faut modifier</li><li>L'administrateur change les données du livres.</li><li>L'administrateur confirme la modification des coordonnées saisies.</li><li>Le système met à jour les informations</li><li>Une confirmation des modification de donnée est affichée</li></ol> |
| Scénarios alternatifs    | <ul><li>Si un ISBN est le même qu'un autre livre saisie, envoyer un message d'erreur.</li><li>En cas d'erreur de saisie d'une des données, demande de correction.                                                                                                                                                                                                            |
